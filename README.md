# 🧮 Calculator Website

A modern and responsive Calculator Website built from scratch using **HTML, CSS, JavaScript**, and later upgraded with **Python (Flask)**.

This project is part of my journey to becoming a **Full Stack Python Developer**. Instead of just copying code, I am building every feature step by step while learning real software development practices.

---

## 🚀 Project Goal

The goal of this project is to understand:

* Frontend Development
* JavaScript Logic Building
* Responsive UI Design
* Git & GitHub Workflow
* Clean Code Structure
* Problem Solving
* Software Development Life Cycle (SDLC)

Later, this project will be integrated with **Python Flask** to make it a full-stack web application.
